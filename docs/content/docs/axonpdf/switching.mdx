---
title: Switching
description: Move a project from the React PDF renderer API to axonpdf by changing one import or adding an npm alias.
icon: ArrowRightLeft
---

`@axonpdf/react` follows the React PDF renderer API: the same components, props, style keys, units,
`StyleSheet`, `Font` methods, render functions, browser components and error messages. A project
that uses that API can switch without changing its document code.

## Change the import

Install axonpdf, remove the old package, and replace the old package name in your imports:

```sh
npm install @axonpdf/react
```

```tsx
import { Document, Page, Text, renderToFile } from '@axonpdf/react';
```

## Or keep the imports and use an npm alias

If the old name appears in many files, or in code you don't own, alias it in `package.json` and
leave the imports alone. The renderer's package name goes on the left:

```json
{
  "dependencies": {
    "<the renderer package>": "npm:@axonpdf/react"
  }
}
```

That one alias covers components, render functions, `Font`, `StyleSheet` and the browser
components.

If your code also imports the renderer's separate font, stylesheet or types packages, change those
imports to `@axonpdf/react`. It exports `Font`, `StyleSheet`, `Style`, `PageSize`, `SourceObject`
and the other types, and has no separate packages for them:

```ts
import { Font, StyleSheet, type Style } from '@axonpdf/react';
```

A hyphenation package that gives you a `(word) => parts` function plugs into
`Font.registerHyphenationCallback` as before. Add-on packages that return styles, or draw with the
Svg components, run on axonpdf's styles and Svg components, but they haven't been tried one by one.

## What behaves differently

| Area                 | Difference                                                                                                                                                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| React versions       | React 18 and 19 are supported. Earlier versions are not.                                                                                                                                                                                         |
| Creator and producer | A `Document` without `creator` or `producer` writes `axonpdf` in both.                                                                                                                                                                           |
| Streaming            | `renderToStream`, `renderToFile` and `toBuffer` send each page as soon as it is finished, instead of laying the whole document out first. `toBuffer` waits for the last page only when the `Document` has an `onRender` prop, so `onRender` is still called before you get the stream. |
| Bookmarks            | A bookmark's `left` is measured from the page's left edge.                                                                                                                                                                                       |
| Gradients            | A radial gradient runs from its focal point (`fx`, `fy`) to its outer circle, as SVG defines it. `gradientTransform` angles are degrees, and `skewX` and `skewY` act on the right axes.                                                          |
| Checkboxes           | An unchecked checkbox is blank.                                                                                                                                                                                                                  |
| Floats               | Floats sit inside their parent's padding, and a float whose text wraps pushes the content below it down.                                                                                                                                         |
| Rendering            | A document is rendered by walking its elements once, without mounting it in a React reconciler. Hooks get their first-render values and effects don't run. The render falls back to a full reconciler for `React.lazy`, legacy context and `setState` during render. |

The bookmark, gradient, checkbox and float rows fix bugs in how the usual renderer draws. If a
document worked around one of them, remove the workaround.

Everything else should come out the same. If a page renders differently, open an issue at
[github.com/axonpack/axonpdf](https://github.com/axonpack/axonpdf/issues) with the document.

## Check the result

Render a few of your real documents before and after the switch and compare them. One way is to
rasterise both files and compare the pages:

```sh
pdftoppm -png -r 72 before.pdf before
pdftoppm -png -r 72 after.pdf after
```

Small differences in antialiasing are normal. A different page count or a moved block is not.
