## Components and hooks

| Export                         | What it is                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------- |
| `PreviewProvider`              | `{ config: PreviewConfig, children }`. Mount it near the root, on every start |
| `PreviewList`                  | The ready-made list. Props below                                              |
| `usePreview()`                 | The list and its actions. Needs the provider above it                         |
| `useRunning()`                 | What this start runs, as a [`Running`](#running). Needs the provider          |
| `usePreviewsState()`           | The raw [store state](#usepreview), without the provider                      |
| `useDevPreviewServersState()`  | `{ servers, activeUrl, error }` for dev preview servers                       |

## PreviewList props

`PreviewList` is a FlatList, and takes FlatList's props as well as its own.

| Prop                    | What it is                                                                   |
| ----------------------- | ---------------------------------------------------------------------------- |
| `theme`                 | Colours, radius and fonts. See [Theme](#theme)                               |
| `labels`                | Any text. See [Labels](#labels)                                              |
| `style`                 | The FlatList's style, over the list's background colour                      |
| `contentContainerStyle` | Over the list's padding: 16 all round and 112 at the end, which clears a floating tab bar. Set `paddingBottom` to fit your own |
| `ListHeaderComponent`   | Your own element above the list's header (the error banner and the header card) |
| `ListFooterComponent`   | Your own element after the last row                                          |
| Any other FlatList prop | Passed through, such as `onScroll`, `testID` or `showsVerticalScrollIndicator` |

The list keeps these for itself, so they can't be passed: `data`, `getItem`, `getItemCount`,
`renderItem`, `keyExtractor`, `ItemSeparatorComponent`, `CellRendererComponent`, `getItemLayout`,
`numColumns`, `columnWrapperStyle`, `horizontal`, `refreshing`, `onRefresh`, `refreshControl` (pull
to refresh is built in, coloured from the theme) and `ListEmptyComponent` (the list always has its
section headings, and says itself when nothing is published).

## PreviewConfig

What the app passes to the provider. Nothing here is read from the environment.

| Field                 | Needed | What it is                                                                          |
| --------------------- | ------ | ----------------------------------------------------------------------------------- |
| `enabled`             | Yes    | `true` turns previews on. You decide per build; nothing is detected                 |
| `url`                 | Yes    | With a read key: `<endpoint>/<bucket>[/<folder>]`, the same as `PREVIEW_S3_URL`. Without one: any address the files are public under, such as that URL, `https://pub-<id>.r2.dev` or a CDN |
| `readAccessKeyId`     | No     | A read-only key, for a private bucket. Never the write key                          |
| `readSecretAccessKey` | No     | Its secret                                                                          |
| `region`              | No     | Signing region for a private bucket. Default `us-east-1`; `auto` on R2              |
| `headers`             | No     | Extra headers on every read, for a proxy, CDN or tunnel in front of the bucket      |
| `devPreviewServers`   | No     | Lists this app's Metro servers in a debug build. Default off. See [Dev preview servers](/docs/preview/dev-preview-servers) |
| `buildKey`            | No     | This build's key, only when the config plugin is not used to bake it in             |

## usePreview

| Field                  | What it is                                                                 |
| ---------------------- | -------------------------------------------------------------------------- |
| `enabled`              | `config.enabled`                                                           |
| `devPreviewServers`    | Whether dev preview servers are on                                         |
| `items`                | [`PreviewItem[]`](#previewitem): this build's previews, and downloads it no longer lists |
| `incompatible`         | Downloads made for another native build                                    |
| `loading`              | A refresh is running                                                       |
| `error`                | The last error, as text, or null                                           |
| `buildKey`             | This build's key, or null without the plugin                               |
| `remote`               | What the bucket lists for this build. Null until it has answered once      |
| `local`                | Every download on the device                                               |
| `downloading`          | Download progress by id, from 0 to 1                                       |
| `activeId`             | The preview the next start loads, or null for the default bundle          |
| `broken`               | Ids of previews that stopped before they finished starting                 |

| Action                   | What it does                                                             |
| ------------------------ | ------------------------------------------------------------------------ |
| `refresh()`              | Reads the downloads, then asks the bucket for this build's list          |
| `download(id)`           | Downloads a preview, or its update                                       |
| `switchTo(id)`           | Restarts into a preview, downloading it first if needed                  |
| `switchTo(null)`         | Back to the default bundle. Also stops a dev preview server              |
| `remove(id)`             | Deletes a download. If it runs, goes back to the default bundle first    |
| `removeIncompatible()`   | Deletes every download made for another native build                     |

### PreviewItem

| Field      | What it is                                                                       |
| ---------- | -------------------------------------------------------------------------------- |
| `id`       | The preview's id                                                                 |
| `entry`    | The bucket's entry: `title`, `branch`, `commit`, `author`, `publishedAt`, `appVersion`, `buildNumber`, `compatibility`, `fingerprint`, `size`, `changelog`, `revision`, `manifest` |
| `status`   | `available`, `downloading`, `downloaded`, `update-available`, `unpublished` or `broken` |
| `progress` | 0 to 1 while downloading, else null                                              |
| `active`   | It is the one the next start loads                                               |
| `local`    | The download on the device, or null                                              |

### Running

| `kind`     | Fields                                                             |
| ---------- | ------------------------------------------------------------------ |
| `default`  | `source` (`built-in`, `expo-dev-server` or `dev-preview-server`), `url`, `hostPort`, `server` |
| `preview`  | `id`, `title`                                                      |
| `local`    | `url`, `hostPort`, `server` (null until the list has found it)     |

## Functions

| Function                      | What it does                                                                 |
| ----------------------------- | ---------------------------------------------------------------------------- |
| `selectPreview(id, key?)`     | Chooses what the next start or `reload()` loads: a preview id, or null for the default bundle. False where the native module is missing |
| `reload()`                    | Restarts JS, so a new choice takes effect. False where the native module is missing |
| `previewBundlePath(id)`       | Where a preview's bundle sits, relative to the preview folder                |
| `markLaunched()`              | Tells the native side this start worked. The provider calls it               |
| `buildKey()`                  | The key the plugin baked into this build, or null                            |
| `buildCompatibility()`        | `appVersion` or `fingerprint`, as baked in, or null                          |
| `buildSlug()`                 | The app's slug, as baked in, or null                                         |
| `previewTitle(id)`            | The readable title for an id: `task-1-login-fix` becomes "Task 1 login fix"  |
| `previewItems(state)`         | `{ items, incompatible }` from the store state                               |
| `runningNow(input)`           | The pure form of `useRunning()`                                              |
| `resolveTheme(theme, scheme)` | A full list theme from a partial one and the device's colour scheme         |

`previewsStore` and `devPreviewServersStore` are the stores behind the hooks, with `getState()` and
`subscribe()`, for use outside React.

## Theme

`PreviewList`'s `theme` takes any of these. `LIGHT_THEME` and `DARK_THEME` are the defaults.
A chip's text is its tone on a light wash of it; where the tone would be hard to read on the card
or the header's tint, its text is darkened (or lightened, on a dark theme) just enough. A tone that
is not a hex colour gets an outline instead of a wash. From an expo-devtools palette, `info`,
`accent2` and `accent3` come from its `codeKeyword`, `jsonNumber` and `jsonString`.

| Token         | What it colours                                            |
| ------------- | ---------------------------------------------------------- |
| `mode`        | `auto` (follows the device), `light` or `dark`. Default `auto` |
| `background`  | Behind the list                                            |
| `card`        | Each card                                                  |
| `surface`     | Behind the changelog and the progress track                |
| `tint`        | A wash of the primary colour: the header card and chips    |
| `tintBorder`  | The header card's border, which `border` would lose on the tint |
| `border`      | Card and button borders                                    |
| `title`       | Headings                                                   |
| `text`        | Body text                                                  |
| `muted`       | Quiet text: branch, author, date, size                     |
| `primary`     | Main buttons                                               |
| `primaryText` | Text on main buttons                                       |
| `danger`      | Delete, errors, Unpublished and Broken                     |
| `dangerSurface` | Behind the error banner                                  |
| `warning`     | Update available, a build warning, and the Metro note      |
| `success`     | Active and Downloaded                                      |
| `info`        | The Expo server chip and the branch line                   |
| `accent2`     | The Preview server chip                                    |
| `accent3`     | The environment chip                                       |
| `radius`      | Card corner radius. Buttons scale from it. Default 14      |
| `fonts`       | `{ regular, medium, bold }` font family names. Each falls back to the system font |

## Labels

`PreviewList`'s `labels` takes any of these. `DEFAULT_LABELS` has the defaults.

| Label                    | Default                                                                       |
| ------------------------ | ----------------------------------------------------------------------------- |
| `title`                  | Previews                                                                      |
| `running`                | Running                                                                       |
| `base`                   | Embedded bundle                                                               |
| `backToDefault`          | Use the default bundle                                                        |
| `backToBase`             | Deprecated: use `backToDefault`. Still shown when `backToDefault` is not set  |
| `metroBypassed`          | Debug build: Metro is not used while a preview runs. Use the default bundle to load from Metro again. |
| `errorUnreachable`       | Can't reach the bucket at {host}.                                             |
| `errorEmulatorHint`      | On the Android emulator, use \`10.0.2.2\`, or run \`adb reverse tcp:{port} tcp:{port}\`. The second line, on Android when the bucket is on localhost. Text between backticks shows in a code font |
| `errorForbidden`         | The bucket refused access.                                                    |
| `errorForbiddenHint`     | Check the read key or the bucket's policy. None when you set `errorForbidden` and not this |
| `errorNotFound`          | The bucket or the file was not found.                                         |
| `errorNotFoundHint`      | Check the bucket URL in the preview config. None when you set `errorNotFound` and not this |
| `errorGeneric`           | Something went wrong. The raw message goes on the second line                 |
| `retry`                  | Retry                                                                         |
| `dismiss`                | Dismiss                                                                       |
| `refresh`                | Refresh                                                                       |
| `empty`                  | No previews published for this build yet.                                     |
| `noBuildKey`             | This build has no compatibility key, so it cannot list previews. Add the config plugin and rebuild. |
| `download`               | Download                                                                      |
| `switchTo`               | Switch                                                                        |
| `update`                 | Update                                                                        |
| `delete`                 | Delete                                                                        |
| `status`                 | One per status: Not downloaded, Downloading, Downloaded, Update available, Unpublished, Broken: it stopped while starting |
| `branchPrefix`           | Branch:. Before the branch name on a row                                      |
| `environmentPrefix`      | env:. Before the environment name on its chip. A screen reader says `environment` instead |
| `byline`                 | {author}, {time}. Who published a preview and when                            |
| `timeAgo`                | `now` Just now, `minute` 1 minute ago, `minutes` {n} minutes ago, `hour` 1 hour ago, `hours` {n} hours ago, `day` 1 day ago, `days` {n} days ago. Older than 30 days shows the date |
| `showMore`               | Show more                                                                     |
| `showLess`               | Show less                                                                     |
| `incompatibleTitle`      | Incompatible                                                                  |
| `incompatibleHint`       | Made for another native build, so they can't run here.                        |
| `deleteAll`              | Delete all                                                                    |
| `devPreviewServersTitle` | Dev preview servers                                                           |
| `devPreviewServersHint`  | Metro servers for this app on your computer.                                  |
| `defaultServerTitle`     | Default. The title of the Metro the app starts on, when `preview start` gave it none |
| `switchToServer`         | Switch to {title}, {address}. What a screen reader says for a server row      |
| `switchToServerHint`     | Restarts the app on this server.                                              |
| `noDevPreviewServers`    | No Metro server found. Start one with npx preview start.                      |
| `noBuildSlug`            | This build has no app slug, so it cannot tell its servers from other apps'. Add the config plugin and rebuild. |
| `stopDevPreviewServer`   | Deprecated: no longer shown. Use the default bundle stops a picked server     |
| `localSuffix`            | local                                                                         |
| `localIncompatible`      | Made for another native build                                                 |
| `localUnknownBuild`      | Native build unknown                                                          |

`status` and `timeAgo` are merged per key, so `labels={{ status: { broken: 'Crashed' } }}` changes
only that one.

## Config plugin

```json
["@axonpack/preview", { "compatibility": "appVersion" }]
```

| Option          | Default      | Values                       |
| --------------- | ------------ | ---------------------------- |
| `compatibility` | `appVersion` | `appVersion` or `fingerprint` |

See [Compatibility](/docs/preview/compatibility) for what it writes into the build.
