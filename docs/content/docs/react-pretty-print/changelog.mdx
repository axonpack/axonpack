## 0.1.0

<ReleaseMeta date="10 September 2026" bump="minor" npm="https://www.npmjs.com/package/@axonpack/react-pretty-print/v/0.1.0" />

- **JSON and XML viewers** — expand and collapse any value or document, with a preview on every closed node
- **Syntax highlighting for 38 languages** — JavaScript and TypeScript through YAML, SQL, diffs and logs
- **One implementation for React and React Native** — pass in your own container, text and pressable components; a web set ships with the package
- **Search across all three views** — matching runs are painted, and only the branches holding a match open
- **Match case, whole word and regular expression** search modes
- **Node actions** — expand or collapse a subtree, or copy any value as formatted JSON
- **130 palettes**, or write your own from a flat set of colour roles
- **Minified source is re-indented** before it is shown, and that can be turned off
