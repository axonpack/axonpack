```ts
import type { DevtoolsConfig, Palette } from '@axonpack/expo-devtools';
```

## Configuration

`DevtoolsConfig`, `DevtoolsNetworkConfig`, `DevtoolsConsoleConfig`, `DevtoolsPerformanceConfig`,
`DevtoolsStorageConfig`, `DevtoolsQueryConfig`, `DevtoolsNavigationConfig`, `DevtoolsReduxConfig`,
`DevtoolsCrashConfig`, `DevtoolsAiUsageConfig`, `DevtoolsProviderProps`, `DevtoolsPanelControls`,
`DevtoolsWebViewProps`, `DevtoolsErrorBoundaryProps`.

## Theming

`BuiltInThemeId`, `ThemeId`, `ThemeConfig`, `Palette`, `StatusBarStyle`.

## Network

`NetworkEntry`, `NetworkLogEntry`, `NetworkLogStatus`, `WebSocketLogEntry`,
`ResolvedNetworkConditions`, `ThrottlePresetId`, `ThrottleProfile`, `UserAgentPresetId`.

## Console

`ConsoleLogEntry`, `ConsoleLogLevel`.

## Performance

`LongTaskEntry`, `MemorySample`, `StartupTiming`, `UserTimingEntry`, `MarkOptions`, `MeasureOptions`.

## Storage

`StorageAdapter`, `StorageAdapterConfig`, `StorageAdapterDefinition`, `StorageAdapterKind`,
`StorageKeyBlacklist`, `StorageAdapterState`, `StorageEntry`, `StorageReadResult`, `StorageValueType`,
`StoredValueKind`, `AsyncStorageLikeDriver`, `MmkvLikeDriver`, `SecureStoreLikeDriver`.

## Query

`QueryClientLike`: the part of a TanStack Query v5 `QueryClient` the Query tab calls, its two caches
and `refetchQueries`, `invalidateQueries`, `resetQueries` and `removeQueries`.

## Navigation

`NavigationMove`, `NavigationRoute`, `NavigationRouterKind`, `NavigationState`,
`NavigationContainerRefLike`, `NavigationContainerLike`.

## Redux

`ReduxAction` (a plain object with a string `type`), `ReduxActionEntry` (one row: `id`, `timestamp`,
`type`, `action`, `prevState`, `state`), `ActionTypeMatcher` (`string | RegExp`, for `redux.allow` and
`redux.deny`).

## Crash

`CrashRecord`, `CrashKind`, `CrashBreadcrumb`, `CrashBreadcrumbCategory`, `CrashDeviceInfo`,
`CrashNativeDetail`, `CrashPopupDetail`.

## Values, not types

Alongside the factories and components, the package root also exports `formatCrashReport` and
`formatCrashJson` for turning a `CrashRecord` into Markdown or JSON yourself.
