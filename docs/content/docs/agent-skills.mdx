Axonpack has one agent skill, `axonpack`, for every package. A skill is a `SKILL.md` file your
coding agent loads when a task needs it. This one holds no API or setup steps of its own. It sends
the agent to these docs, starting from [`llms.txt`](https://axonpack.dev/llms.txt), and has it
follow the [agent guide](/docs/agent-guide) to set a package up. The docs always describe the latest
release, so the skill matches it, and it covers packages published after you installed it.

## Install it

Run this in your app's project folder:

| Package manager | Command                               |
| --------------- | ------------------------------------- |
| npm             | `npx skills add axonpack/skills`      |
| yarn            | `yarn dlx skills add axonpack/skills` |
| pnpm            | `pnpm dlx skills add axonpack/skills` |
| bun             | `bunx skills add axonpack/skills`     |

The CLI lists the coding agents it finds on your computer, then installs the skill into the project
for the ones you pick. It needs Node 22.20 or newer, and `yarn dlx` needs Yarn 2 or later.

## Choose on the command line

The examples use `npx`. The other forms take the same flags.

```sh
# Show the skill without installing anything
npx skills add axonpack/skills --list

# One agent, with no questions
npx skills add axonpack/skills -a <agent> -y
```

- `-a` takes the name of any agent the CLI supports. Its
  [agent list](https://github.com/vercel-labs/skills/blob/main/docs/agents.md) has the names and
  where each one keeps its skills.
- `-g` installs for your user instead of this project, so every project on the computer has it.

## What the skill reads

The skill fetches these, so anything that can fetch a URL can use them too:

| URL                                                         | What it holds                                                                      |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `https://axonpack.dev/llms.txt`                             | Every page, grouped by package, with a one-line description and its markdown URL   |
| `https://axonpack.dev/llms.mdx/docs/agent-guide/content.md` | The [agent guide](/docs/agent-guide): where to look, and how to set up any package |
| `https://axonpack.dev/llms-full.txt`                        | Every page in one file                                                             |

## Without the CLI

The skill is the [`skills/axonpack`](https://github.com/axonpack/skills/tree/main/skills/axonpack)
folder in the [axonpack/skills](https://github.com/axonpack/skills) repository. Copy it to wherever
your agent reads skills from.

For `@axonpack/expo-devtools` alone, [Use with AI agents](/docs/expo-devtools/ai-agents#tell-your-agent-about-it)
has a short snippet for your `AGENTS.md` or `CLAUDE.md` instead.
