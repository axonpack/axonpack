- **CLI tab**: the AI Usage tab is now called CLI, in the app and in React Native DevTools
- **`devtools cli`**: the tab's topic is now `cli`, and its replies start `# CLI`. `devtools ai-usage` still works, but is deprecated
- **`cli.disabledByDefault`**: opens the CLI tab paused. `aiUsage` still works, but is deprecated, and `cli` wins when both are set
